# banana18 Wiki

Welcome to the `banana18` wiki.

`banana18` is an 18-month public build toward an Agent Evaluation &
Reliability Platform.

Project rule:

> Every meaningful deliverable earns three numbers: QUALITY, COST, and LATENCY.

Use this page as the main index for project documents and the monthly plan.
